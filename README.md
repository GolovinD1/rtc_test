# Тестовое задание Elhart: Автотесты RTC
## Выполнил Головин Дмитрий

Решение 4-го этапа тестового задания на позицию Тестировщика. 

Проект представляет собой архитектуру для автоматического тестирования часов реального времени контроллера Alpha-X. Поскольку доступ к физическому оборудованию на этапе написания тестов отсутствует, реализован программный Mock-объект, повторяющий API контроллера.

## Структура проекта

Все исходные файлы логики и тестов инкапсулированы во внутренней директории `alpha_x`:

* `alpha_x/alpha_x.h` — Заголовочный файл с интерфейсом объекта.
* `alpha_x/alpha_x.cpp` — Реализация математики хода времени с автоматической нормализацией дат через стандартную библиотеку `<ctime>` (корректная обработка високосных годов и переходов через полночь).
* `alpha_x/alpha_x_test.cpp` — Стенд автоматизированного тестирования на базе **Boost.Test**.
* Корень проекта — конфигурация независимой кроссплатформенной сборки (`CMakeLists.txt`, `CMakePresets.json`).

## Зависимости и сборка

* Компилятор с поддержкой C++17/20.
* **CMake** (версия 3.8 или выше).
* **Boost.Test** (Header-only вариант). Путь к заголовочным файлам Boost передается через `CMakePresets.json`.

## Результаты тестирования

Успешное прохождение краевых случаев: 

1. Проверка на смену дня, при переходе через полночь
2. Проверка на високосный год
3. Проверка на правильный вывод строки
